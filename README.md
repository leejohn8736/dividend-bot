Dividend Alert Bot 📈🤖

주식 배당락일 이틀전인 고배당 종목을 매일 아침 텔레그램 채널로 알려주는 자동화 봇

GitHub Actions

✨ 주요 기능

NASDAQ 공식 배당 캘린더 API 사용
배당 수익률 3% 이상 종목 필터링
텔레그램 채널/그룹/개인 채팅으로 자동 발송
GitHub Actions 기반 무료 스케줄링
